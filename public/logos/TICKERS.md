# Logo drop-in checklist (your held tickers)

Save each company's logo as a PNG with the file name below and place it in this
folder. It overrides the monogram automatically on the next build. Missing files
just keep the monogram — no error, no external request.

Sources to grab a logo from: the company's own website, its page on
casablanca-bourse.com, Wikipedia, or a domain logo CDN (e.g. open
`https://logo.clearbit.com/<company-domain>` in a browser and save the image).
